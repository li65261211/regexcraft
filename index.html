FAQ

    
Is RegexCraft free?

    
Yes. RegexCraft is completely free to use, with no signup, no account and no usage limits.

    
Which regex flavor does it use?

    
JavaScript — the same regular expression engine built into your browser. Any pattern accepted by new RegExp(pattern, flags) works here, so what you test is what your code will see.

    
Does my pattern or test text leave my browser?

    
No. Everything runs 100% locally in your browser. Nothing is uploaded, stored or sent anywhere.

    
What flags are supported?

    
All JavaScript regex flags: g (global), i (ignore case), m (multiline), s (dotAll), u (unicode) and y (sticky). Toggle them with the flag chips above the test area.

    
Can I use it on mobile?

    
Yes. RegexCraft is fully responsive and works in any modern mobile browser.
